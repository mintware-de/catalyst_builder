# Catalyst Builder Runtime

This is the runtime package for [catalyst_builder](https://pub.dev/packages/catalyst_builder).
It contains the `ServiceContainer`, the annotations and the interfaces — and has no dependencies.

Add it as a regular dependency to your app or plugin package:

```yaml
dependencies:
  catalyst_builder_runtime: ^7.0.0
```

The code generator lives in [catalyst_builder](https://pub.dev/packages/catalyst_builder) and is
added as a dev dependency:

```yaml
dev_dependencies:
  build_runner: ^2.4.0
  catalyst_builder: ^7.0.0
```

For more details head over to the [wiki](https://github.com/mintware-de/catalyst_builder/wiki)
